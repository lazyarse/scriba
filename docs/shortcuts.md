# Shortcuts

## Scriba

| Shortcut | Action |
|---|---|
| Ctrl+Alt+P | Preferences |
| Ctrl+Q | Quit |
| Ctrl+B | Toggle Preview Layout |
| F11 | Toggle Fullscreen |
| Ctrl+Shift+D | Debug Log |
| Alt+1–0 | Switch between open tabs (0 = tab 10) |

## Files

| Shortcut | Action |
|---|---|
| Ctrl+N | New |
| Ctrl+O | Open |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save As |
| Ctrl+R | Reload .md |
| Ctrl+P | Print / Export PDF |
| Ctrl+Shift+W | Export as Word (DOCX) |
| Ctrl+Shift+H | Export as HTML |

## Editor

| Shortcut | Action |
|---|---|
| Ctrl+F | Find / Replace |
| F3 | Next Search Result |
| Shift+F3 | Previous Search Result |
| Ctrl+D | Duplicate Line |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z | Redo |
| Ctrl+X | Cut |
| Ctrl+C | Copy |
| Ctrl+V | Paste |
| Ctrl+A | Select All |
| Down | On last line, place cursor at end |
| Tab | Indent selected text |
| Shift+Tab | Dedent selected text |
| Ctrl+Up | Jump cursor up to previous header or rule |
| Ctrl+Down | Jump cursor down to next header or rule |
| Ctrl+Alt+Up | Scroll viewport up |
| Ctrl+Alt+Down | Scroll viewport down |

## Tables

| Key | Context | Action |
|---|---|---|
| Tab | Inside a cell | Move to next cell |
| Tab | Last cell of a row | Move to first cell of next data row |
| Tab | No next row | Normal Tab |
| Shift+Tab | Inside a cell | Move to previous cell |
| Shift+Tab | First cell of a row | Move to last cell of previous data row |
| Shift+Tab | No previous row | Normal Shift+Tab |
| Enter | First row of a new table | Insert separator + data row |
| Enter | Data row | Insert new data row below |
| Enter | Separator row | Normal Enter |
| Enter | Blank row (all cells empty) | Clear row and exit autocomplete |
